# MECHA LAB

### 우주 탐사 로봇팔 제어 시뮬레이션 게임

## 1. 프로젝트 소개
**MECHA LAB**은 사용자가 다관절 로봇팔을 직접 조작하여 우주 탐사 및 정비 임무를 수행하는 웹 기반 시뮬레이션 게임입니다.

로봇팔은 우주 탐사와 산업 현장 등 사람이 직접 작업하기 어려운 환경에서 활용되는 중요한 기계 시스템입니다. 그러나 여러 관절의 회전이 로봇팔 끝부분의 위치와 자세에 어떤 영향을 미치는지 이론만으로 이해하기는 쉽지 않습니다.
이러한 문제에 착안하여, 사용자가 직접 로봇팔의 관절을 회전시키고 물체를 조작하면서 **로봇팔의 운동 원리와 정밀 제어의 중요성**을 체험할 수 있도록 개발하였습니다.
게임은 화성 암석 집기, 배터리 분리, 인공위성 수리의 세 가지 미션으로 구성되어 있으며, 각 미션에는 서로 다른 작업 절차와 제한시간이 적용됩니다.


## 2. 사용법

### ① 게임 시작 및 미션 선택
1. MECHA LAB 웹사이트에 접속합니다.
2. 메인 화면에서 **START GAME** 버튼을 클릭합니다.
3. 화성 암석 집기, 배터리 분리, 인공위성 수리 중 원하는 미션을 선택합니다.
4. 제한시간 내에 로봇팔을 조작하여 주어진 작업을 수행합니다.
5. 성공 또는 실패 결과를 확인하고 다시 도전할 수 있습니다.

메인 화면의 **HOW TO PLAY** 버튼을 통해 기본 조작법을 확인할 수 있습니다.

### ② 로봇팔 조작 방법
- **관절 회전:** 로봇팔의 빨간색 관절을 마우스로 드래그하여 회전합니다.
- **집게 조작:** 집게 끝을 목표 물체에 접근시킨 뒤 Space 키 또는 버튼을 눌러 물체를 잡거나 놓습니다.
- **물체 이동:** 물체를 잡은 상태에서 관절을 움직여 원하는 위치로 운반합니다.
- **재시작:** 다시 시작 버튼을 누르면 해당 미션을 처음부터 진행할 수 있습니다.

각 관절의 회전에 따라 로봇팔 말단의 위치가 달라지므로, 목표 지점에 도달하기 위해서는 여러 관절의 움직임을 조합해야 합니다.


## 3. 주요 기능 설명


### ① 다관절 로봇팔 제어
세 개의 회전 관절을 가진 로봇팔을 구현하였습니다.
- 각 관절을 마우스 드래그로 독립적으로 회전
- 관절마다 서로 다른 회전 민감도 적용
- 관절 회전각에 따른 로봇팔 말단 위치 계산
- 집게를 이용한 물체 집기 및 이동
- 집게와 목표 지점 사이의 거리를 이용한 접촉 판정
이를 통해 여러 관절의 회전이 전체 로봇팔의 위치와 자세에 영향을 미치는 원리를 체험할 수 있습니다.


### ② 미션별 작업 수행

#### MISSION 01 — 화성 암석 집기 🪨
**제한시간: 1분 30초**
화성 표면에 놓인 암석을 로봇팔로 집어 샘플 보관함까지 운반하는 미션입니다.

- 로봇팔을 이용한 암석 집기 및 운반
- 암석을 놓쳤을 때 중력에 따른 낙하와 구르기 구현
- 샘플 보관함 내부 도착 여부에 따른 성공 판정

#### MISSION 02 — 배터리 분리 🔋
**제한시간: 2분**
우주 장비의 잠금장치를 해제하고 배터리를 분리하는 미션입니다.

- 잠금장치 해제
- 로봇팔을 이용한 배터리 추출
- 배터리 이동 거리에 따른 진행률 계산

#### MISSION 03 — 인공위성 수리 🛰️
**제한시간: 4분**
우주 공간에서 인공위성의 여러 부품을 정해진 절차에 따라 정비하는 미션입니다.

작업은 다음 여섯 단계로 진행됩니다.
1. 위성 보호 덮개 제거
2. 제어 버튼 A 작동
3. 제어 버튼 B 작동
4. 슬라이드 스위치 조작
5. 빨강·파랑·노랑·초록 전선을 해당 색상의 소켓에 연결
6. 움직이는 전파 신호 지점에 안테나 정렬


### ③ 제한시간 및 성공·실패 판정
각 미션에는 서로 다른 제한시간이 설정되어 있으며, 남은 시간이 화면에 실시간으로 표시됩니다.
- 미션별 제한시간 표시
- 목표 위치 및 작업 조건 충족 여부 확인
- 제한시간 내 작업 완료 시 성공 처리
- 제한시간 초과 시 실패 처리
- 재시작을 통한 반복 도전


### ④ 물리 현상 및 동적 환경 구현
게임의 현실감과 조작 경험을 높이기 위해 여러 동적 요소를 구현하였습니다.
- 중력에 따른 화성 암석의 낙하
- 바닥에 떨어진 암석의 구르기와 속도 감소
- 시간에 따라 위치가 변하는 전파 신호
- 우주 배경의 별과 행성 이동
- 배터리 이동 및 작업 진행 상태의 실시간 반영


### ⑤ 게임 인터페이스 및 애니메이션
레트로 픽셀 아케이드 스타일을 적용하여 게임의 시각적 특징을 강화하였습니다.
- 우주 테마의 시작 화면과 미션 선택 인터페이스
- 미션별 작업 안내 및 진행 상태 표시
- 성공 시 로봇팔 춤과 파티클 효과
- 실패 시 로봇팔 파손 애니메이션
- 미션 특성에 맞춘 개별 성공 연출
